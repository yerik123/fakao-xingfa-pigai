# 法考主观题·刑法 批改

把考生提交的**刑法案例分析作答**，按法考真实的**采点给分**逻辑，批成一份能直接照着改的批改报告。

核心判断：**法考主观题不是"读作文"，是"找采分点"。** 罪名写对不等于得分——结论只占很小比重，剩下八成在"要件拆开、事实塞进去"的涵摄过程，以及观点展示是否完整。

## 一、功能范围

**覆盖：**
- 法考主观题**刑法案例分析题**（一问一答型、一句话问法型、观点展示型）。
- 单题批改、多题批量批改、同一道题的多次作答对比（进步追踪）。
- 只要结论的"速批"、要完整报告的"详批"。

**不覆盖（必须如实说明，不要硬批）：**
- 刑诉、民法、民诉、商法、行政法、法治思想论述题——本 skill 的评分细则只针对刑法。遇到其他科目，只能给通用层的意见（结论有无、层次是否清楚、字数），并明确告知"该科目细则不在本 skill 范围内"。
- 法律文书写作题（起诉书/判决书格式）。
- **押题与预测**：只批改已作答内容，不预测考题。

**硬性前提：必须有题干。** 只有答案没题干，无法定位命题人设置的采分点，不能批改。此时先向用户要题干（可让用户发图片）。

## 二、输入形式

| 形式 | 处理方式 |
|---|---|
| A. 直接粘贴 | 题干 + 作答都在对话里，最常用 |
| B. 图片 | 题干照片 / 手写答题照片。用 `Read` 直接读图（多模态），不要先 OCR——中文手写 OCR 错得离谱 |
| C. 文件 | `.docx` 用 `python-docx`；`.pdf` 用 PyMuPDF 提文字层，**若是扫描件无文字层则转图片后用 `Read` 读图**；`.txt` 直接读 |
| D. 声称"按某年真题答的" | 不认年份，认题干。用户记忆的真题年号常有误，以实际题干为准 |

**开工前必须确认的三件事**（缺哪件就补哪件）：
1. **题干全文**（含每一问的设问原话）
2. **题目分值**（若用户不知道，告知默认值：刑法案例分析题通常约 30–34 分；多问则按问均分，并在报告中标明"分值按均分假设"）
3. **作答版本**（手写稿 / 机打稿；手写稿读不清时，把读出的内容回读给用户确认再批）

## 三、输出形式

默认输出**对话内 Markdown 精简报告**，固定四段。**篇幅口径**：①②③ 与 ④ 的"提升空间"合计控制在 40 行以内；④ 的"全文对照"部分因须保留原文全文，不占这 40 行额度。

```
① 一句话总评（2–3 行）
   【题干关键词 · 设问号】｜ 得分 X / 满分 ｜ 等级
   一句话诊断 = 结论对不对 + 采分点命中率 + 最要命的一两处硬伤。只点病，不铺垫。

② 采分点命中表（含命中率，格式：命中 3.5 / 9）
   采分点 | 判定（✅命中 / ⚠️半对 / ❌遗漏 / ❌错答）
   只列采分点与判定两栏；"说明"一栏默认不写，仅在该点判定有争议时补半句。
   多问时按问分块（甲部分 / 乙部分），或一问一表。

③ 失分处（按分量从大到小排，3–5 条）
   一条一句，统一句式：<丢分点> —— <为什么丢> → <正确判断是什么>
   禁止"论证不够充分""建议加强论证"这类空话。

④ 改写示范（全文对照版）+ 提升空间
   改写示范：**先完整保留、原样展示考生的原始答案全文**，然后就地插入 / 删改。所有改动必须显式标出：
   - 新增或改写后的内容 → 用【】包住并**整体加粗**：**【……】**（加粗是为了从原文里一眼跳出来）
   - 删除的内容 → 用 ~~删除线~~ 标出（不加粗）
   - **未改动的部分原样保留、不加任何符号**（读者扫符号即可定位全部改动）
   段落开头固定加一行图例：> 图例：~~删除~~ ｜ **【新增或改写后】** ｜ 无符号＝原文原样
   多问时按问分块，每问各做一次全文对照；只在一处改动也照此格式，不许改回"原文 → 改写句"的摘录式。
   提升空间：≤3 条，必须是"记住 X，遇到 Y 就想 Z"式的可执行动作。
   末尾一行免责声明。
```

**明确不默认输出的内容（写了就是废话）：**

| 不输出 | 去哪了 |
|---|---|
| 六维评分表（D1–D6 逐项打分与理由） | 改由 `--详批` 触发；默认只在 ① 里报一个采分点命中率 |
| 折算方式推导、等级临界说明、口径漂移讨论 | 同上；除非用户问"怎么算出来的" |
| 参考答案要点长清单（必答 / 加分 / 不必答） | 已融入 ③ 失分处与 ④ 提升空间，不另列 |
| 独立的"提分行动项"段 | 与 ④ 的提升空间合并，不重复写 |
| 对答案优点的长篇肯定、客套话 | 最多一句"X 部分写得扎实"，封顶 |

> 底层理由：用户要的是**修订清单**，不是**判决书**。一句话能说清的不写两句；同一件事不在两个段落各说一遍。

**可选输出**（用户要求时才做）：

| 参数 | 作用 |
|---|---|
| `--详批` | 输出完整七段版：① 总评 ② 采分点逐问核对表（带"说明"栏）③ 六维评分表 ④ 原文级修改建议 ⑤ 参考答案要点清单 ⑥ 提分行动项 ⑦ 免责声明。适合逐维复盘或留档 |
| `--只给分` | 只输出 ① 的一句话总评 |
| `--含范文` | 在 ④ 后补一份 1000 字左右、符合"正式答案版"风格的完整范文 |
| `--导出 Word` | 报告是正式交付物，用户要文件时转 `.docx`（优先走 `tencent-docx` 技能，或本地 `python-docx`） |

**语气**：直说，不客套。用户要的是"哪丢分了、怎么改"，不是安慰。但批评必须落到具体原文，不许空泛说"论证不够充分"。**能一句说清的绝不写两句。**

## 四、批改维度与评分标准（六维，满分 100，再折算到题分）

> **六维是内部算分工具，默认不落到报告上。** 默认报告只呈现"采分点命中率 + 估算得分 + 等级"；六维逐项打分表仅在 `--详批` 时输出。理由：逐维打分表会占掉报告三成篇幅，且形式分（D3/D5/D6）容易把"漏了半道题的采分点"掩盖过去，让考生误以为答得不错。

| 维度 | 权重 | 一句话核心 |
|---|---|---|
| D1 考点覆盖（采分点命中率） | 30 | 命题人设的点，你答到几个？ |
| D2 定性准确与涵摄充分 | 25 | 罪名/形态对不对？理由有没有落到该罪的构成要件？ |
| D3 规范表达与法条引用 | 10 | 是不是法言法语？引用的条号案例有没有引错？ |
| D4 逻辑论证与观点展示 | 20 | 说理自不自洽？该展示的两种观点齐不齐？ |
| D5 卷面结构与文字表达 | 10 | 分层清不清、结论有没有前置、字数控没控住？ |
| D6 答题纪律与前后呼应 | 5 | 问什么答什么、漏点有没有回填、结论有没有及时修正？ |

**折算公式**：估算得分 = 题目分值 ×（六维加权得分率）

**等级**：A 优秀 ≥85%｜B 良好 70–84%｜C 及格 60–69%｜D 不及格 <60%

**D3 有一条特殊规则，最容易批错，必须记住：**
> 柏浪涛明确：刑法答题**不要求**写"根据《刑法》第 X 条"，**不要求**写司法解释名称，不写**不扣分**。所以刑法批改里 **不能因为"没引法条"扣分**。这一维度考的是"法言法语"（有没有把大白话转成规范表述），以及"引了的话有没有引错"。这与民法、诉讼法"必须摆大前提援引法条"的习惯相反，不要串味。

细则、每维的具体扣分点、采分点核对表、十大常见失误 → `references/rubric.md`

## 五、批改流程（五步，第 2 步不许跳）

1. **建档**：确认题型（一问一答 / 一句话问法）、分值、设问数；把每一问的**设问原话**抄下来单独列。
2. **批改者先独立作答**：自己先把这道题做一遍，列出**采分点清单**（答案要点 + 必答项），**然后**才去看考生答案。
   - 这一步是批改质量的分水岭。先读考生答案再"反推考点"，会被他的错误逻辑带着走，把漏掉的采分点也漏判。
3. **逐问比对**：把考生答案按采分点拆开，逐点判定 ✅ / ⚠️ / ❌，并记录"他是怎么写的"（用于第 ④ 段原文级建议）。
4. **六维打分 + 折算总分 + 定等级**。六维逐项打分是**内部算分步骤**，默认不落到报告上（只在 `--详批` 时输出）；默认报告只报一个"采分点命中率 + 估算得分 + 等级"。
5. **出报告**：按第三节的**四段结构**。

**遇到争议点**：如果考生结论与主流观点不同但论证自洽（观点展示题的常态），**不要判错**，按"观点展示完整性"给分，并注明"该点为学说争议，你的观点属少数说，形式论证成立"。

## 六、使用方式

**触发方式**
- 对话直接粘贴题干与作答（最常用）。
- 发图片（题干、手写答题纸）。
- 发文件（.docx / .pdf / .txt）。
- 斜杠命令：`/fakao-xingfa-pigai`。

**可选参数**（写在请求开头，可叠加）

| 参数 | 作用 |
|---|---|
| `--详批` | 输出完整七段版（含六维评分表、参考答案要点清单、提分行动项），适合逐维复盘或留档 |
| `--严格` | 按真实阅卷口径卡（严卡采分点、严卡"只给结论"），分数偏保守 |
| `--宽松` | 默认。要点有、论证弱也酌情给分，偏鼓励 |
| `--只给分` | 只出总评一段 |
| `--含范文` | 附 1000 字左右完整范文 |
| `--批量` | 多题一次提交，逐题批改 + 末尾汇总表（题号 / 得分 / 等级 / 共同短板） |
| `--对比` | 同一题的两次作答，做平行对比，标出"这次比上次多拿了什么分" |

**默认口径**：精简四段式（见第三节）；`--严格` / `--宽松` 只影响分数口径，不影响输出篇幅。

**多题/多轮约定**：用户连续提交时，默认保持同一份评分口径；若上一次批改的等级与本次差距大，主动提示可能是口径漂移。

## 七、示例（默认四段式，照此格式输出）

**输入**（用户粘贴）：

> 【题干·一问一答型】甲来到自行车修理店，欲非法占有一辆新的电动自行车，谎称要买一把锁，让店主去库房拿货。店主离开后，甲骑走电动自行车。
> 【问题】甲的行为构成何罪？请说明理由。
> 【我的答案】甲构成诈骗罪。理由是甲虚构买锁的事实，欺骗了店主，店主基于认识错误交付了财物，所以构成诈骗罪。

**输出**：

```
**自行车案 · 问题 1 ｜ 得分 2 / 6 ｜ D 不及格**

**一句话**：结论错，采分点 0 / 3。理由挂在了错误的构成要件上——"谎称买锁"只是让店主受骗去取锁，店主从未处分那辆自行车。

**采分点命中（0 / 3）**

| 采分点 | 判定 |
|---|---|
| 定性为盗窃罪（而非诈骗罪） | ❌ 错答 |
| 关键要件：诈骗罪第三步"被害人基于认识错误而处分财物"不成立 | ❌ 遗漏 |
| 甲以平和手段对财物实施转移占有 | ❌ 遗漏 |

**失分处**

1. **罪名答错** —— 把"欺骗"等同于诈骗罪，但诈骗罪的落脚点是"处分行为"，本题店主只处分了"一把锁"。→ 正确定性是**盗窃罪**。
2. **核心理由未落地** —— 你写"店主基于认识错误交付了财物"，而采分点要的是"被害人**没有对电动自行车**实施处分"。→ 本题写这一个要件就够。
3. **转移占有环节空白** —— 盗窃罪的落脚点"甲以平和手段转移占有"没写。→ 补一句即可。

**改写示范（全文对照）**

> 图例：~~删除~~ ｜ **【新增或改写后】** ｜ 无符号＝原文原样

甲构成~~诈骗罪~~**【盗窃罪，不构成诈骗罪】**。理由是~~甲虚构买锁的事实，欺骗了店主，店主基于认识错误交付了财物，所以构成诈骗罪~~**【甲虽虚构买锁的事实使店主受骗，但店主只处分了"一把锁"，并未对电动自行车作出处分；甲是趁店主离开、无人看管之际，以平和手段将该车转移为自己占有】**。

**提升空间**

1. 记住口诀：**"被害人有没有'处分财物'，是盗窃与诈骗的分水岭。"** 遇到"被骗但财物被拿走"的案情，第一反应查处分行为。
2. 理由只写**关键要件**，不罗列完整构成要件清单——写全清单既费时间又不加分。
3. 写完自问一句：**"我的理由，有没有正好落在两个罪的区别点上？"**

（得分按柏浪涛方法论估算，非官方阅卷分。）
```

> `--详批` 的完整七段版示例（含六维评分表、参考答案要点清单）见 `references/moban.md`。

## 边界与诚实要求

- 得分是**估算**，每次都要标"非官方阅卷分数"。
- 分值未知时用默认假设，并**显式写出假设**，不要假装知道。
- 观点展示题里，考生选少数说但论证自洽的，**不许判错**。
- 材料读不清（手写模糊、题干残缺）时，**停下来问**，不要猜着批。
