# 法考主观题·刑法 AI 批改 Skill

> 一个让 AI 按**真实阅卷口径**批改法考刑法案例分析题的 Agent Skill。  
> 不是"作文点评"，是把**采分点**逐条拆出来、算命中率、按分量排序失分处，最后给一份能直接照着改的修订稿。

---

## 一、它解决什么问题

法考主观题备考最大的缺口是**没人批改**。

客观题对错立判，主观题不是。刑法案例分析题按**采点给分**：罪名写对只占很小比重，**八成的分在"要件拆开、事实塞进去"的涵摄过程，以及观点展示是否完整**。考生自己对照参考答案，通常只能看出"结论对不对"，看不出分丢在哪一步。

把题目直接丢给通用 AI，得到的往往是"你的思路基本正确，建议加强论证的充分性"——这类反馈无法执行，等于没批。

本 skill 要解决的就一件事：**让反馈落到具体的那一句话上，让考生知道下一笔该改哪里。**

---

## 二、设计上的几个关键判断

| 设计                                                                                        | 为什么这么做                                                              |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **采点给分，不是读作文**                                                                            | 法考阅卷按采分点给分。批改报告的第一张表就是"命题人设的点，你命中几个"。                               |
| **批改者必须先独立作答**                                                                            | 这是批改质量的分水岭。先读考生答案再"反推考点"，会被他的错误逻辑带着走，把他漏掉的采分点一起漏判。流程上强制先列采分点清单，再对照。 |
| **六维评分模型**（D1 考点覆盖 30 / D2 定性涵摄 25 / D4 逻辑与观点展示 20 / D3 规范表达 10 / D5 卷面结构 10 / D6 答题纪律 5） | 让"估算得分"有稳定口径，而不是凭印象。六维是内部算分工具，默认不占报告篇幅。                             |
| **全文对照式改写**                                                                               | 不另写一份"范文"让你无从对照。完整保留你的原答，新增用 `【】` 加粗、删除用删除线、未改动部分零标记——扫符号即可定位全部改动。  |
| **默认只出四段、正文 ≤40 行**                                                                       | 考生要的是**修订清单**，不是**判决书**。六维评分表、参考答案长清单等留档内容改由 `--详批` 触发。             |
| **刑法不因"没引法条"扣分**                                                                          | 刑法答题不要求写"根据《刑法》第 X 条"，不写不扣分；这跟民法、诉讼法"必须摆大前提"的习惯相反。这条最容易批错，写进了强制规则。  |
| **参考文件分层加载**                                                                              | 评分细则、考点快查、报告模板每次必读（共约 100KB），34KB 的真题答案库只在批改到对应年份时才读，避免无效占用上下文。     |
| **观点展示题不许判错**                                                                             | 考生选少数说但论证自洽，按"观点展示完整性"给分，并注明其为少数说。                                  |

## 三、怎么用

**安装**：把 `fakao-xingfa-pigai/` 整个目录放进你的 Agent Skills 目录（如 `~/.workbuddy/skills/` 或项目的 `.workbuddy/skills/`）。本 skill 为标准 Agent Skill 格式（SKILL.md + frontmatter），兼容支持该格式的 Agent 环境。

**触发**：对话里直接粘贴「题干 + 你的作答」，或发题干照片 / 手写答题照片（走多模态读图，不走 OCR，中文手写 OCR 错得离谱），或上传 `.docx` / `.pdf` / `.txt`。

**可选参数**（写在请求开头，可叠加）：

| 参数              | 作用                                  |
| --------------- | ----------------------------------- |
| `--详批`          | 完整七段版（含六维评分表、参考答案要点清单、提分行动项），适合留档复盘 |
| `--严格` / `--宽松` | 分数口径：严卡采分点 / 要点有但论证弱也酌情给分（默认宽松）     |
| `--只给分`         | 只要一句话总评                             |
| `--含范文`         | 附一份约 1000 字的完整范文                    |
| `--批量`          | 多题一次批改 + 末尾汇总表（题号 / 得分 / 等级 / 共同短板） |
| `--对比`          | 同一题两次作答平行对比，标出"这次多拿了什么分"            |
| `--导出 Word`     | 报告转 `.docx` 交付                      |

**硬性前提**：必须有题干。没有题干无法定位命题人设置的采分点，不予批改。

## 四、真实样例

**输入**（考生提交）：

> 【题干】甲来到自行车修理店，欲非法占有一辆新的电动自行车，谎称要买一把锁，让店主去库房拿货。店主离开后，甲骑走电动自行车。  
> 【问题】甲的行为构成何罪？请说明理由。  
> 【我的答案】甲构成诈骗罪。理由是甲虚构买锁的事实，欺骗了店主，店主基于认识错误交付了财物，所以构成诈骗罪。

**输出**（默认四段式，原文输出）：

---

**自行车案 · 问题 1 ｜ 得分 2 / 6 ｜ D 不及格**

**一句话**：结论错，采分点 0 / 3。理由挂在了错误的构成要件上——"谎称买锁"只是让店主受骗去取锁，店主从未处分那辆自行车。

**采分点命中（0 / 3）**

| 采分点                            | 判定   |
| ------------------------------ | ---- |
| 定性为盗窃罪（而非诈骗罪）                  | ❌ 错答 |
| 关键要件：诈骗罪第三步"被害人基于认识错误而处分财物"不成立 | ❌ 遗漏 |
| 甲以平和手段对财物实施转移占有                | ❌ 遗漏 |

**失分处**

1. **罪名答错** —— 把"欺骗"等同于诈骗罪，但诈骗罪的落脚点是"处分行为"，本题店主只处分了"一把锁"。→ 正确定性是**盗窃罪**。
2. **核心理由未落地** —— 你写"店主基于认识错误交付了财物"，而采分点要的是"被害人**没有对电动自行车**实施处分"。→ 本题写这一个要件就够。
3. **转移占有环节空白** —— 盗窃罪的落脚点"甲以平和手段转移占有"没写。→ 补一句即可。

**改写示范（全文对照）**

> 图例：~~删除~~ ｜ **【新增或改写后】** ｜ 无符号＝原文原样

甲构成~~诈骗罪~~**【盗窃罪，不构成诈骗罪】**。理由是~~甲虚构买锁的事实，欺骗了店主，店主基于认识错误交付了财物，所以构成诈骗罪~~**【甲虽虚构买锁的事实使店主受骗，但店主只处分了"一把锁"，并未对电动自行车作出处分；甲是趁店主离开、无人看管之际，以平和手段将该车转移为自己占有】**。

**提升空间**

1. 记住口诀：**"被害人有没有'处分财物'，是盗窃与诈骗的分水岭。"** 遇到"被骗但财物被拿走"的案情，第一反应查处分行为。
2. 理由只写**关键要件**，不罗列完整构成要件清单——写全清单既费时间又不加分。
3. 写完自问一句：**"我的理由，有没有正好落在两个罪的区别点上？"**

（得分按柏浪涛方法论估算，非官方阅卷分。）

## 六、边界（说了才敢用）

- **只覆盖刑法案例分析题**。刑诉、民法、民诉、商法、行政法、论述题、法律文书写作题不在本 skill 的评分细则范围内，遇到时如实说明，不硬批。
- **不做押题与预测**，只批改已作答内容。
- **得分是估算**，每次报告都标注"非官方阅卷分数"；分值未知时显式写出均分假设。
- **材料读不清就停下来问**，不猜着批。
